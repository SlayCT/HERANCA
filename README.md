# 📚 Atividade 10 — Herança

Atividade desenvolvida na disciplina de **Técnicas de Programação**, com foco no uso de **Interfaces, Herança e Polimorfismo** na Programação Orientada a Objetos (POO), utilizando a linguagem Java.

## 🎯 Objetivo

Praticar a criação e implementação de interfaces, a reutilização de métodos e a aplicação de regras específicas em diferentes classes.

A atividade trabalha três exercícios:

* 👥 **Funcionários:** interface `Funcionario` e classes `Gerente`, `Vendedor` e `Faxineiro`, com métodos gerais e específicos para cada função.
* 💳 **Pagamentos:** interface `Pagamento` e classes `PagamentoCartao` e `PagamentoDinheiro`, aplicando taxas e descontos, além da emissão de recibos.
* 🔐 **Autenticação:** interface `Autenticavel` e classe `SistemaSeguranca`, com validação de login, autenticação e logout.

## 🛠️ Tecnologias utilizadas

* ☕ Java
* 💻 Programação Orientada a Objetos (POO)
* 🔗 Interfaces e implementação de métodos
